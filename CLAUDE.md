# FleshFall Discord Bot

RPG Discord bot for the FleshFall (เมดเนื้อ) horror ARG world. TypeScript + discord.js v14, ESM (`"type": "module"`, NodeNext → imports use `.js` extensions).

## Read first
- `.claude/lore.md` — canon world summary (source of truth for content)
- `.claude/game-design.md` — how lore maps to mechanics, balance numbers, content rules
- `.claude/lore-source.txt` — full original Google Doc text (large; grep it, don't read whole)

## Commands
```bash
npm run dev        # tsx watch
npm run typecheck  # tsc --noEmit — run after every change
npm run deploy     # register slash commands (needed when command definitions change)
npm run api        # web API alone (http://localhost:3001/api, read-only player data)
npm run web:data   # snapshot game content → web/src/data/game.json (site works without the bot)
npm run web:dev    # Next.js site (web/, http://localhost:3000, static)
npm run build && npm start
```
Env in `.env` (see `.env.example`): `DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID`, `DATA_FILE`.

## Layout
- `src/index.ts` interaction router · `src/deploy-commands.ts`
- `src/commands/` slash commands (register in `commands/index.ts`)
- `src/interactions/buttons.ts` button handlers (`ev:` event choice, `dg:` dungeon nav)
- `src/interactions/panels.ts` menu panels (`pn:` buttons, `pns:` selects; all replies ephemeral) · images `assets/panels/`
- `src/game/zones.ts` zones (city inside a region, e.g. paris ⊂ old_realm), timed travel (`TRAVEL_MINUTES`) · `src/game/hunt.ts` monsters + 3-monster hunts, door drops · `src/interactions/hunt.ts` hunt UI (`hn:`)
- Location channels (one category per continent, "Old Realm - <Continent>"): 50 cities from `CITIES` in zones.ts (7 continents × easy/normal/hard/epic). Discord caps 50 channels per category. Members with `Administrator` (and the server owner) bypass overwrites and see every city. Continent → main door (Europe gray/Loki, Asia orange/Beelzebub, America + South America blue/Belphegor, Africa green/Sophia, Australia yellow/Hastur, Antarctica white/Wendigo). Tier (`TIERS`) scales monster hp/dmg/AC/hit/xp/loot. Rouge Land has no channel. Cypress Isle has its own channel + `📍 Cypress Isle` role (`channel: true`, `travel: false`: only the red door leads there, no shop/hunt; leave via ferryman/black-door events, 🧭 or 🏠)
- Travel picker = continent dropdown → city dropdown (`pns:travelc` then `pns:travel:<continent>`); `/travel` and `/panel` use autocomplete (>25 choices)
- New city = add a row to `CITIES` → gets a `/panel` entry + a `📍 <Name>` location role automatically (channel itself must be created + panel posted). **Also add its `[lat, lon]` to `CITY_COORDS` in `src/render/mapCard.ts`** or it gets no dot on the travel map
- Travel map (`src/render/mapCard.ts`, panel 🧭 travel): Natural Earth 110m land outlines (`assets/map/land-110m.json`, public domain), one dot per city (color = continent door, size = tier), red ring = you. Picking a continent in `pns:travelc` re-renders zoomed to that continent with city names
- `src/zoneRoles.ts` location roles: member holds only their current zone's role (none while traveling); zone channels visible only to that role. 15s tick resolves travel + syncs; every interaction also syncs
- Dev mode (God mode): Discord role `Dev` (env `GOD_ROLE`) → `src/game/dev.ts` `isDev(char)`; refreshed per interaction in `index.ts`. Skips travel time/gates, shop/upgrade/cook costs, cooldowns, stamina, Closing Shift. Combat damage unchanged
- Expedition loop: Butchery 🗺️ ออกสำรวจ → pick city → arrive **instantly** (leaving Rouge Land is instant). City panel: hunt / explore / continent shop (`CONTINENT_STOCK`) / travel (city→city, `TRAVEL_MINUTES`) / 🏠 return to Rouge Land (`TRAVEL_MINUTES`). Hunt end offers ล่าต่อ / door / 🏠
- Rouge Land facilities (cafe/bar buy+sell, cook, drink, upgrade) require being home (`homeError` in actions.ts); continent shop requires standing in a city (`fieldError`). Panels tag field shop ids with `:field`. Profile/inventory/use/equip/rest/pray work anywhere. God bypasses home gate
- Extraction loop (`src/game/expedition.ts`): **one inventory**. An expedition round = leave Rouge Land → come back. Loot gained out there (`gainItem` in character.ts — hunt drops + event rewards) is pending in `Character.trip.loot`, not usable, delivered into the inventory on arriving home (`resolveTravel` / `applyOutcome` travel → `endTripSafe`, notice in `char.banked`). **Dying before home = no haul this round** (`loseTrip`), inventory never touched, respawn at home. `trip.streak` = hunts won this trip → loot ×(1+0.15/step, cap 8), rare-drop bonus, but Miasma on each new hunt + monster dmg. Field shop sells at 70% (`FIELD_SELL_MULT`). Outsiders without Rouge Land (`reachedRougeLand=false`) have no bag — loot goes straight to inventory
- Role economy: Hound kills drop 🫀 `hunted_flesh` (45%, others 8%; raw = humanity −5) → Bar-only buff recipes (`RECIPES[].barOnly`, item `buff` = timed stat/def bonus in `Character.buff`, `activeBuff` feeds `statMod`/`gearDef`) → Maid `/serve @user item` (`serveFood`: +1 bonus, ×1.5 duration, Maid tip, Patron tips ×2) → Patron hires via the market
- Player market (`src/game/market.ts` logic, `src/interactions/market.ts` UI, `/market`, panel `market`): sell listings escrow items, buy requests escrow flesh; fill = partial as much as possible; Rouge Land only; 3-day TTL auto-refund (lazy in `listOrders`); max 3 orders (Patron 6); filling a Patron buy order pays +20% tip. Orders stored in db `market` (`Store.allOrders/saveOrder/deleteOrder`). Owner gets a best-effort DM. Panel buttons `pn:mkt*`, selects `pns:mkt*`, modals `pnm:<sell|buy>:<item>` (routed in index.ts)
- Icon dungeons (`src/game/blessings.ts`): each dungeon rolls on entry (`startRun` in engine.ts) — 5% if door = current continent's main color, 1% elsewhere (God 100%). Only Icon dungeons offer the shrine exit, of the DOOR's Icon (not the player's). Shrine = +1 blessing tier of that Icon (+2 for followers, max 5, permanent stat perk `BLESSING_PERK`). Sophia shrine also gives `sophia_rite` → `/revive @user` un-Fiends a friend
- Rendered UI cards (`src/render/`, `@napi-rs/canvas` = Skia; Thai shaping OK): `kit.ts` shared fonts/palette/ornaments (design system tokens), Thai word-wrap via `Intl.Segmenter`, emoji via Twemoji COLR fallback font · `profileCard.ts` · `itemCards.ts` (inventory/shop/forge — take pre-computed data, no `commands/` imports) · `sceneCards.ts` (hunt battle, event/dungeon banner) · `view.ts` `imagePayload()` = image embed + optional text embed, falls back to the old embed on error. Payload builders: `profilePayload`/`eventPayload`/`dungeonPayload` (ui.ts), `inventoryPayload`/`shopPayload`/`upgradePayload` (actions.ts), `huntPayload` (interactions/hunt.ts). Art from `web/public`, fonts in `assets/fonts/` (OFL + Twemoji CC-BY)
- Dice animation: d20 checks record a `DiceRoll` (`src/game/dice.ts`; hunt `RoundResult.dice`, event `ChoiceResult.dice` incl. Loki re-rolls). `src/render/diceGif.ts` draws a tumbling d20 GIF (gifenc, plays once) landing on the real face (nat20 gold / nat1 / "ขาดอีก N!"); `playDice` (`src/interactions/dice.ts`) shows it on the deferred message with buttons removed, waits, then the caller swaps in the result. State is saved before the animation. `DICE_ANIM=0` disables
- Duel (`/duel @user`, just for fun): `src/game/duel.ts` pure logic (fighters snapshotted, duel HP = 60% max HP, stats halved so luck dominates; ฟาด / ทุ่มสุดตัว −4 hit ×1.75 dmg / ตั้งการ์ด +4 AC + heal d4 / ยอมแพ้). Real character never changes. `src/interactions/duel.ts` (`du:`) keeps duels **in memory only** (restart drops them), public message, dice GIF per attack, 60s challenge / 90s turn timeouts (stall = forfeit), one duel per user
- Card rules: callers `deferReply`/`deferUpdate` before rendering (3s window), but **mutate + save before the first await** (`exploreStart` is sync → `exploreView` renders). Payloads always carry `files` — updates must pass `files: []` (see `toUpdate`) to clear an old card image
- `src/commands/actions.ts` shared actions (use/equip/buy/sell/cook/rest/pray) returning `ActionResult` — reuse from both slash commands and panels
- `src/game/` pure game logic — `types.ts`, `roles.ts`, `icons.ts`, `items.ts`, `world.ts`, `character.ts`, `engine.ts`, `events/`
- Monorepo (npm workspaces): bot = repo root, website = `web/` (`@fleshfall/web`, Next.js 16 App Router, React 19, Cache Components on). **Next 16 differs from training data — read `web/AGENTS.md` + `node_modules/next/dist/docs/` before changing web code.** Static game data (world/icons/roles/items/bestiary) is a bundled snapshot `web/src/data/game.json` read via `useGame` (`web/src/lib/game.ts`) — **re-run `npm run web:data` after changing game content**. **Pages are static — no live game data** (no status/leaderboard); the only dynamic parts are the `/create` account route handlers (`web/src/app/api/`). Types for API shapes live in `web/src/lib/types.ts` (keep in sync with `src/web/api.ts`)
- Web API: `src/web/server.ts` (node:http, JSON only) + `src/web/api.ts` (world/icons/roles/items/bestiary/leaderboard/status, read-only). Runs inside the bot when `API_PORT` is set; `src/web/standalone.ts` (`npm run api`) points the store at a temp file and reads the live db fresh (never writes it). Never expose Discord user ids
- Web design rules: **`web/designsystem.md`** (FGO-like ornate base in blood palette + light NIKKE "Dossier accents": backdrop wordmark/band, Brackets, plate corners; no tag chips/index ticks — `components/Dossier.tsx`, `app/dossier.css`; still no //// stripes/cut corners/grids). Follow it for any new web UI
- Web images: `web/public/{background,asset,icons}` as **webp** with descriptive kebab-case names (≤2560px backgrounds, ≤1800px others). Carousel shows every file in `background/` sorted by name (`01-…`, `02-…`). Art registry: `web/src/lib/art.ts`, Icon art: `IconGallery.tsx`
- Known issue: `eslint` in web/ fails because root TypeScript 7 is hoisted and typescript-eslint rejects it; `next build` type-checks fine (web has its own TS 5)
- **Website character creation** (`/create`): characters are made on the site, not in Discord (`/start` just links there when `WEB_URL` is set). Flow: Discord OAuth (`identify guilds.join`, `web/src/app/api/auth/*`) → AES-GCM session cookie (`web/src/lib/server/session.ts`, holds the OAuth token) → Vercel route handlers `web/src/app/api/me/*` call the bot's **private** `/api/account/*` (`src/web/account.ts`, `Authorization: Bearer API_SECRET`, user id only from the verified session) → bot creates the character + `guild.members.add` with the token (no public invite needed). One character per Discord id; only a Fiend may re-create. Players can rename on the site (`rename`, 1h cooldown in `cooldowns.rename`; Discord nickname is never touched); `accountView.status` feeds the dossier stat strip. Optional `REQUIRE_CHARACTER=1` kicks members who join without one (needs Server Members intent)
- Character images: slots in `src/game/account.ts` `IMAGE_SLOTS` (portrait/art/sheet ×1, gallery ×6; exported to game.json `imageSlots`). Browser resizes → webp, POSTs to `/api/me/images`; server sniffs magic bytes, ≤4MB (Vercel body cap), writes to **Cloudflare R2** via `aws4fetch` (`web/src/lib/server/r2.ts`), then the bot stores only the key (`Character.images`, keys `chars/<uid>/<slot>-<rand>.<ext>`, validated by `isOwnKey`). Public URL = `R2_PUBLIC_URL` + key. Replaced/deleted images are removed from R2. Profile card (`profileCard.ts`) draws the player's own art (`pickImage`: art → portrait → gallery) fetched from `IMAGE_BASE_URL` + key via `remoteArt` (kit.ts, in-memory cache), falling back to `ROLE_ART`. Env: root `.env.example` + `web/.env.example`
- Character sprite (paper doll from PSD): player uploads a .psd on `/create`; **parsed in the browser** (`web/src/lib/psd.ts`, `ag-psd`) — each visible top-level **group or layer = one part** (merged art = one layer per part), composited (opacity kept), trimmed, scaled to fit 3.8MB, webp. `web/src/lib/rig.ts` maps group names → part ids (`classify`: hair_tail_l/r, back_hair, bang, back_acc_l/r, weapon, skirt, torso, eyes, head, arm_l/r, leg_l/r; side from name else canvas half; unknown → `extra_*` static) and defines the shared skeleton (pivot + parent per kind; weapon hangs from the nearest hand) + `idlePose` animation; blink = frame swap Head → `Head Blink` (`visibleAt`), falls back to squashing eyes when there's no blink layer; iris is a child of eyes; `SpriteStage.tsx` draws it with Canvas2D. Upload = `/api/me/sprite` (multipart rig + `p_<id>` files) → R2 `sprites/<uid>/<rand>/<id>.<ext>` → bot `sprite/set` stores manifest in `Character.sprite` (`cleanSprite` validates). Pivots/animation live in code, not in saves, so tweaking rig.ts applies to everyone. Grab-the-torso physics in `web/src/lib/puppet.ts` (body = pendulum from grab point, limbs = angular springs driven by body accel, drop + bounce + squash, eyes shut while held); legs/skirt/torso are roots so feet stay planted. Test offline by passing an @napi-rs/canvas `CanvasKit` to `parsePsd`
- Template sprite: `web/public/templates/fleshfall-sprite-template.psd` (download on /create) → `npm run web:template` splits it into `web/public/sprites/template/*.webp` + `web/src/data/sprite-template.json` (default sprite before a player uploads). Re-run when the template PSD changes. Script lives in `web/scripts/` (excluded from both tsconfigs, run by tsx)
- RP proxy (`src/rpProxy.ts` (not `proxy.ts`: Next 16 treats that name as middleware), Tupperbox-style): when `PROXY=1`, messages in every channel/thread except `PROXY_EXCLUDE` (channel or category names, default `ทั่วไป,Archive`) are reposted via a per-channel webhook (`FleshFall Proxy`) as the character (name + portrait→art→gallery from R2, else role art from `WEB_URL`), original deleted after the repost succeeds. Skips `\`, `//`, `(( ))` OOC and players without a character; replies get a quote line; only user mentions ping. Turns on GuildMessages + **privileged MessageContent** intents only when enabled. Discord nicknames are never set
- VM deploy: pm2 app = `bash -c "npm run build && exec node dist/index.js"` (see `ecosystem.config.cjs`) → `git pull && npm install && pm2 restart fleshfall` rebuilds automatically. `exec` keeps SIGINT reaching node so db.json flushes
- `src/db/store.ts` JSON file store (sync, atomic writes). Swap impl, keep API.

## Conventions
- In-game text is **Thai**; proper nouns (Icon names, M.A.I.D.S, Miasma, Rouge Land, Fiend) stay English.
- Game logic stays Discord-free (`src/game/`), so it can be smoke-tested offline with tsx.
- Event `resolve()` returns an `Outcome`; never mutate the character inside events. `applyOutcome` handles death / breakdown / Fiend.
- Never `await` between loading a character and saving it (store relies on sync load→mutate→save).
- Bump `CHAR_VERSION` in `types.ts` when the Character shape changes incompatibly (old saves are discarded).
- Only the 7 canon Icons. Skip the doc's "Secret Record" content.
