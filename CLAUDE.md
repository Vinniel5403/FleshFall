# FleshFall Discord Bot

RPG Discord bot for the FleshFall (เมดเนื้อ) horror ARG world. TypeScript + discord.js v14, ESM (`"type": "module"`, NodeNext → imports use `.js` extensions).

## Read first
- `.claude/lore.md` — canon world summary (source of truth for content)
- `.claude/game-design.md` — how lore maps to mechanics, balance numbers, content rules
- `.claude/lore-source.txt` — full original Google Doc text (large; grep it, don't read whole)

## Commands
```bash
npm run dev        # tsx watch
npm run typecheck  # tsc --noEmit — run after every change
npm run deploy     # register slash commands (needed when command definitions change)
npm run api        # web API alone (http://localhost:3001/api, read-only player data)
npm run db -- "<SQL>"  # query/edit the live player db (safe while the bot runs)
npm run web:data   # snapshot game content → web/src/data/game.json (site works without the bot)
npm run web:dev    # Next.js site (web/, http://localhost:3000, static)
npm run build && npm start
```
Env in `.env` (see `.env.example`): `DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID`, `DATA_FILE`.

## Layout
- `src/index.ts` interaction router · `src/deploy-commands.ts`
- `src/commands/` slash commands (register in `commands/index.ts`)
- `src/interactions/buttons.ts` button handlers (`ev:` event choice, `dg:` dungeon nav)
- `src/interactions/panels.ts` menu panels (`pn:` buttons, `pns:` selects; all replies ephemeral) · images `assets/panels/`
- `src/game/zones.ts` zones (city inside a region, e.g. paris ⊂ old_realm), timed travel (`TRAVEL_MINUTES`) · `src/game/hunt.ts` monsters + 3-monster hunts, door drops · `src/interactions/hunt.ts` hunt UI (`hn:`)
- Location channels (one category per continent, "Old Realm - <Continent>"): 50 cities from `CITIES` in zones.ts (7 continents × easy/normal/hard/epic). Discord caps 50 channels per category. Members with `Administrator` (and the server owner) bypass overwrites and see every city. Continent → main door (Europe gray/Loki, Asia orange/Beelzebub, America + South America blue/Belphegor, Africa green/Sophia, Australia yellow/Hastur, Antarctica white/Wendigo). **Every city has a level** (6th field of a `CITIES` row: easy 1–3, normal 4–6, hard 8–10, epic 12, Australia 14, Antarctica 16; `zoneLevel`) = the base level of every monster hunted there (+ `huntStreakLevels` per hunt won this trip) — the hunter's level never changes monsters. Tier now only picks the roster (`TIER_SPAWN` weights) + colour/label. Cities above your level only warn (`cityRisk`: ⚠️ above you, 💀 when `levelDC(you, city) ≥ 13`; `riskLabel` in the travel picker, one line on arrival) — nothing is locked. Rouge Land has no channel. Cypress Isle has its own channel + `📍 Cypress Isle` role (`channel: true`, `travel: false`: only the red door leads there, no shop/hunt; leave via ferryman/black-door events, 🧭 or 🏠)
- Travel picker = continent dropdown → city dropdown (`pns:travelc` then `pns:travel:<continent>`); `/travel` and `/panel` use autocomplete (>25 choices)
- New city = add a row to `CITIES` → gets a `/panel` entry + a `📍 <Name>` location role automatically (channel itself must be created + panel posted). **Also add its `[lat, lon]` to `CITY_COORDS` in `src/render/mapCard.ts`** or it gets no dot on the travel map
- Travel map (`src/render/mapCard.ts`, panel 🧭 travel): Natural Earth 110m land outlines (`assets/map/land-110m.json`, public domain), one dot per city (color = continent door, size = tier), red ring = you. Picking a continent in `pns:travelc` re-renders zoomed to that continent with city names
- `src/zoneRoles.ts` location roles: member holds only their current zone's role; zone channels visible only to that role. **On the road they keep the departure city's role until arrival** (`currentZone` only moves in `resolveTravel`) — stripping it on departure hid the channel together with the ephemeral travel reply. 15s tick resolves travel + syncs; every interaction also syncs
- On the road (`char.traveling`) = **one plain message everywhere**: `travelNotice(char)` in zones.ts (`🏠 **กำลังเดินทางกลับ Rouge Land** — ถึง <t:…:R> (<t:…:t>)` / `🧭 **กำลังเดินทางไป <city>**` + one footnote; Discord timestamps so it never goes stale). `travelAction` answers with it on departure, and everything blocked repeats it — no map, no pickers, no buttons: panel gate `roadBlock` in panels.ts (every `pn:`/`pns:` action except `ON_ROAD` = profile/inv/use/equip/rest/pray; in-place views are replaced by the notice), old hunt cards (`handleHuntButton`), `homeError`/`fieldError`/`marketError`/`exploreStart`/`startTravel`. Profile shows the headline only (`travelLine`). New travel-blocked action = call `travelNotice`, never write another wording
- Dev mode (God mode): Discord role `Dev` (env `GOD_ROLE`) → `src/game/dev.ts` `isDev(char)`; refreshed per interaction in `index.ts`. Skips travel time/gates, shop/upgrade/cook costs, cooldowns, stamina, Closing Shift. Combat damage unchanged. `/dev` (`src/commands/dev.ts`, logic `src/game/devTools.ts`, Dev role only, ephemeral): `hunt count deep heal` = auto-fight N hunts in the current city (hits the weakest monster, doors skipped; streak reset each hunt unless `deep`), `give item qty user`, `heal user`, `level level user` (up only, via normal level-ups), `flesh amount user`
- Expedition loop: Butchery 🗺️ ออกสำรวจ → pick city → arrive **instantly** (leaving Rouge Land is instant). City panel: hunt / explore / continent shop (`CONTINENT_STOCK`) / travel (city→city, `TRAVEL_MINUTES`) / 🏠 return to Rouge Land (`TRAVEL_MINUTES`). Hunt end offers ล่าต่อ / door / 🏠. Finding a door: hunt win `balance.huntDoorChance` (20%, Icon colours by the city's `doorWeights`); explore `balance.exploreDoorChance` (1%, rolled on its own in `pickEvent` — discovery events carry `finds`, so adding events never changes the door rate). **Explore usually finds nothing**: `balance.exploreEmptyChance` (80% overall, `startExplore` in engine.ts → `kind: 'empty'`, stamina still spent) → Old Realm = 80% nothing / 1% door / 19% event; dungeon rooms (`advance`) never roll empty. The red door (→ Cypress Isle) is one of those doors: 7 Icon colours + red, all weight 1 (white/blue/purple from Lv 3)
- Rouge Land facilities (cafe/bar buy+sell, cook, drink, upgrade) require being home (`homeError` in actions.ts); continent shop requires standing in a city (`fieldError`). Panels tag field shop ids with `:field`. Profile/inventory/use/equip/rest/pray work anywhere. God bypasses home gate
- Extraction loop (`src/game/expedition.ts`): **one inventory**. An expedition round = leave Rouge Land → come back. Loot gained out there (`gainItem` in character.ts — hunt drops + event rewards) is pending in `Character.trip.loot`, not usable, delivered into the inventory on arriving home (`resolveTravel` / `applyOutcome` travel → `endTripSafe`, notice in `char.banked`). **Dying before home = no haul this round** (`loseTrip`), inventory never touched, respawn at home. `trip.streak` = hunts won this trip → loot ×(1+0.15/step, cap 8), rare-drop bonus, but Miasma on each new hunt + **monsters climb levels**: next hunt's monster level = city level + streak × `balance.huntStreakLevels` (2, uncapped; `nextHuntLevel` in hunt.ts, stored in `Hunt.lv` so `huntLevel` drives hp/dmg/to-hit/xp/loot). Full-HP win rate at-level: streak 0 ≈ 97–99%, 1 ≈ 60–84%, 2 ≈ 11–55%, 3+ ≈ hopeless → go home. Field shop sells at 70% (`FIELD_SELL_MULT`). Outsiders without Rouge Land (`reachedRougeLand=false`) have no bag — loot goes straight to inventory
- Weapon fusing (forge, panel 🔗 `pn:upg:merge`, `mergeGear` in actions.ts): fuse every spare copy of the equipped weapon into it → `Character.gearMerged[id]` = copies (default 1, cap `MAX_MERGE_COPIES` 16). Hunt damage + `floor(log2(copies))` (`mergeDmg` in character.ts) — damage only, not STR/to-hit; duel ignores it. Rouge Land only
- Global activity feed: game logic calls `feed(char, kind, text)` (`src/game/feed.ts`, Discord-free, no-op without a sink) at milestones (hunt win, rare drop <10%, dungeon exit, shrine, level, home with haul, downed/dying/death, breakdown, Fiend, /wake + /revive, forge +5 / fusing step, duel win, new character). `src/feed.ts` posts batches every `FEED_FLUSH_SECONDS` (20) to `FEED_CHANNEL` (id or name; unset = off), merging repeat hunts (×N) and level-ups; names only, no pings. Dev characters hidden unless `FEED_DEV=1`. New milestone = one `feed()` call + an emoji in `EMOJI`
- Sanity pacing (`balance.huntSanityMult` 0.5 on monster sanity/Miasma per hit, min 1; `streakMiasma` = streak−1; `balance.homeSanityRegen` +1 per 5-min tick while in Rouge Land, in `regen`; rest = +20 home / +8 Old Realm)
- Role economy: Hound kills drop 🫀 `hunted_flesh` (45%, others 8%; raw = humanity −5) → Bar-only buff recipes (`RECIPES[].barOnly`, item `buff` = timed stat/def bonus in `Character.buff`, `activeBuff` feeds `statMod`/`gearDef`) → Maid `/serve @user item` (`serveFood`: +1 bonus, ×1.5 duration, Maid tip, Patron tips ×2; cooked dishes only — `isDish`, so shop tonics `rage_tonic`/`hide_tonic` and `fiend_adrenal` can't be served) → Patron hires via the market
- Player market (`src/game/market.ts` logic, `src/interactions/market.ts` UI, `/market`, panel `market`): sell listings escrow items, buy requests escrow flesh; fill = partial as much as possible; Rouge Land only; 3-day TTL auto-refund (lazy in `listOrders`); max 3 orders (Patron 6); filling a Patron buy order pays +20% tip. Orders stored in db `market` (`Store.allOrders/saveOrder/deleteOrder`). Owner gets a best-effort DM. Panel buttons `pn:mkt*`, selects `pns:mkt*`, modals `pnm:<sell|buy>:<item>` (routed in index.ts)
- Dungeon rooms (`events/dungeons.ts`, `eventPool` in engine.ts): 5–6 ordinary rooms + 1 guardian (`boss: true`) per door. The guardian waits in the last room of only `balance.dungeonBossChance` (20%) of runs (`run.boss`, rolled in `startRun`; `undefined` on old saves = guardian); a run never repeats a room (`run.seen`). The exit opens after the last room either way
- Icon dungeons (`src/game/blessings.ts`): each dungeon rolls on entry (`startRun` in engine.ts) — rare: `balance.iconDungeonHome` (1.5%) if door = current continent's main color, `iconDungeonAway` (0.3%) elsewhere (God 100%). Only Icon dungeons offer the shrine exit, of the DOOR's Icon (not the player's). Shrine = +1 blessing tier of that Icon (+2 for followers, max 5, permanent stat perk `BLESSING_PERK`) **for an offering of 🔯 `sigil`s** (`shrineCost` = `balance.shrineSigilPerTier` × current tier → first blessing free; taken from the inventory, Dev pays too; none = no new tier, `shrineNote` warns on the exit screen). `sigil` is also a consumable (สติ +6, humanity +4). Sophia shrine also gives `sophia_rite` → `/revive @user` un-Fiends a friend (+1 🥚 `placenta`)
- Falling in the field (`fallMode` in character.ts, HP 0 in an Old Realm city): **easy/normal → `downed`** (hunt/run end; a friend in the same city `/wake @user` → 30% HP + timed trip home with the haul; else after `DOWNED_MINUTES` (120) wake up home, trip lost) · **hard/epic → `dying`** (hunt/run kept; `fl:` buttons 🥚 `placenta` revive = 50% HP, fight on · ☠️ give up = normal death + XP in the level → 0; auto give-up after 30 min). Elsewhere = old death. Timeouts resolve lazily in `loadCharacter` (`resolveFall`). `requireActive`/`idleError` block fallen characters (dying gets the buttons back). Results check `stopped(applied)`. **Hunts have no flee** — kill all 3 or fall. 🎒 in a hunt (`hn:<uid>:bag` → select `hns:<uid>`, `useInHunt` in hunt.ts) = use an inventory consumable instead of attacking (heal/stamina/sanity/meal buff), monsters still strike back; trip loot isn't usable until home. **Thrown items** (`ItemDef.blast: [lo, hi]`, `bone_bomb` / `flesh_grenade`) = `throwBomb`: that damage + level/2 to every monster, no roll; only usable from the hunt bag (`useItem`/`consume` refuse them). `placenta` sold at the butchery + Africa shop
- Rendered UI cards (`src/render/`, `@napi-rs/canvas` = Skia; Thai shaping OK): `kit.ts` shared fonts/palette/ornaments (design system tokens), Thai word-wrap via `Intl.Segmenter`, emoji via Twemoji COLR fallback font · `profileCard.ts` · `itemCards.ts` (inventory/shop/forge — take pre-computed data, no `commands/` imports) · `sceneCards.ts` (hunt battle, event/dungeon banner) · `view.ts` `imagePayload()` = image embed + optional text embed, falls back to the old embed on error. Payload builders: `profilePayload`/`eventPayload`/`dungeonPayload` (ui.ts), `inventoryPayload`/`shopPayload`/`upgradePayload` (actions.ts), `huntPayload` (interactions/hunt.ts). Art from `web/public`, fonts in `assets/fonts/` (OFL + Twemoji CC-BY)
- Dice animation: d20 checks record a `DiceRoll` (`src/game/dice.ts`; hunt `RoundResult.dice`, event `ChoiceResult.dice` incl. Loki re-rolls). `src/render/diceGif.ts` draws a tumbling d20 GIF (gifenc, plays once) landing on the real face (nat20 gold / nat1 / "ขาดอีก N!"); `playDice` (`src/interactions/dice.ts`) shows it on the deferred message with buttons removed, waits, then the caller swaps in the result. Every number on the card is captioned (ทอยได้ + <stat> = รวม ≥ ต้องถึง) and the header spells out where the bonus (`DiceRoll.parts`, from `statParts` in character.ts — `statMod` is its sum) and the target (`targetNote`) come from; text logs use `rollTag` (`🎲 2 +16 = 18 · ต้อง 6`). State is saved before the animation. `DICE_ANIM=0` disables
- Combat to-hit by level (`levelDC` in `src/game/dice.ts`): hit when **d20 + mod > 10 + log1.2(defender lv / attacker lv)** (nat 20 / nat 1 still decide). Player → monster: mod = `hitMod` = half STR rounded up + situational bonuses (no level, no weapon — those go to damage). Monster → player: plain d20, target + `evadeMod` (half AGI rounded up, max 5). Monster level = city level + trip streak bonus (`huntLevel` in hunt.ts).
- Hunt scaling (`balance.hunt*PerLevel` in config.ts, `MonsterDef` numbers are Lv 1): per city level above 1 monsters get hp +20%, dmg +15%, xp +25%, and drop +15% more meat/supplies. Player damage = d6 + `floor(level/2)` + weapon (+forge, +fuse) + `floor(STR/2)`, ×2 on nat 20. XP per kill × `xpGap` (monster 3+ levels below you ×0.5, 6+ ×0.2; above you +10%/level, max +50%). Balance check = Monte Carlo with the real code (build a character, loop `startHunt`/`attack`): at-level ≈ 85–100% wins, one level under ≈ 40–85%, four under ≈ hopeless until the high cities
- Hunt drops (`src/game/drops.ts` tables, rolled in hunt.ts `rollLoot`/`salvage`): per kill = the monster's body (`MonsterDef.drops`, only material/consumable stack up with level/streak — gear and relics always ×1) + 10% local goods of the continent (`LOCAL_DROPS`) + 2/3/5/7% tier gear (`TIER_GEAR`; hard/epic hold drop-only pieces no shop sells: butcher_cleaver, revolver, spine_whip, hazmat_suit, knight_sword, chainsaw, fiend_hide, diving_suit, flesh_carapace, flesh_grenade, fiend_adrenal) + 1% the decoration piece that monster guards (`MonsterDef.keepsake`). Once per hunt won = `salvage`: 8% small relic (`VINTAGE_IDS`), 2/3/4/6% by tier (+1% per streak step) a room-decoration piece (`pickDecor`: 16 common + the continent's own 3 pieces, each ×3). **Decoration pieces = `type: 'vintage'` items with `decor: true`** (`DECOR_IDS`; kept out of `VINTAGE_IDS` so ferry fare / Patron commission / event rewards never touch them). They are collectibles until their art exists: add `<Template>-<item>.png` in `assets/rooms-src/`, `npm run web:rooms`, then set `furniture: '<catalog id>'` on the item → placeable Duel: target = levelDC + foe half-AGI (+4 guarding)
- Duel (`/duel @user`, just for fun): `src/game/duel.ts` pure logic (fighters snapshotted, duel HP = 60% max HP, stats halved so luck dominates; ฟาด / ทุ่มสุดตัว −4 hit ×1.75 dmg / ตั้งการ์ด +4 AC + heal d4 / ยอมแพ้). Real character never changes. `src/interactions/duel.ts` (`du:`) keeps duels **in memory only** (restart drops them), public message, dice GIF per attack, 60s challenge / 90s turn timeouts (stall = forfeit), one duel per user
- Card rules: callers `deferReply`/`deferUpdate` before rendering (3s window), but **mutate + save before the first await** (`exploreStart` is sync → `exploreView` renders). Payloads always carry `files` — updates must pass `files: []` (see `toUpdate`) to clear an old card image
- `src/commands/actions.ts` shared actions (use/equip/buy/sell/cook/rest/pray) returning `ActionResult` — reuse from both slash commands and panels. What an item does when used = `itemEffects(id, short?)` in items.ts (cook list/picker/result, `/cook` choices, hunt bag) — never hand-write effect text. The inventory view (`pn:inv`) carries the sell buttons (`inventoryRows`: shop / field merchant / player market) since the static panels can't grow buttons without being re-posted
- `src/game/` pure game logic — `types.ts`, `roles.ts`, `icons.ts`, `items.ts`, `world.ts`, `character.ts`, `engine.ts`, `events/`

## Conventions
- In-game text is **Thai**; proper nouns (Icon names, M.A.I.D.S, Miasma, Rouge Land, Fiend) stay English.
- Game logic stays Discord-free (`src/game/`), so it can be smoke-tested offline with tsx.
- Event `resolve()` returns an `Outcome`; never mutate the character inside events. `applyOutcome` handles death / breakdown / Fiend.
- Never `await` between loading a character and saving it (store relies on sync load→mutate→save).
- Bump `CHAR_VERSION` in `types.ts` when the Character shape changes incompatibly (old saves are discarded).
- Only the 7 canon Icons. Skip the doc's "Secret Record" content.
